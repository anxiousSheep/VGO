## 1. 技术选型总览（已定，无变化）

| 维度 | 选型 | 状态 |
|---|---|---|
| 语言/构建 | C++17 + CMake + MSVC 2022 | ✅ |
| UI | Qt 6 Widgets（含 Network） | ✅ |
| KataGo 接入 | 本地子进程 + GTP over stdio（QProcess） | 🧪 |
| KataGo 模型 | `b18c384nbt-humanv0`（人类风格） | 🧪 |
| 强度标定 | `humanSLProfile` + `temperature` + `humanPolicy` 采样 | 🧪（fallback 已实现随机性） |
| 分析命令 | `kata-analyze`（includeOwnership） | 🧪 |
| LLM 接入 | 抽象 ConversationService + HTTP + 非流式（SSE 计划） | 🧪 |
| 默认 provider | OpenAI 兼容协议（Ollama/DeepSeek/Qwen 等） | 🧪 |
| JSON | Qt QJsonDocument | ✅ |
| 异步 | 核心无 Qt；适配层用 Qt 信号槽（KataGo）/QNetwork | ✅ |
| 配置 | `vgo_config.json` + 密钥不入库 | ✅ |
| 测试 | 自研框架 + CTest；NullEngine/EchoConversation 桩 | ✅ |

## 3. 依赖顺序与验收

**已完成**：`M0 → M1 → M2`（42/42 测试，应用可启动）。

**下一步关键路径**：`M3a.1（AiAdvisor 抽取）→ M3a.2/M3a.3（对话框/猜先）→ M3a.4（摆棋 AI）→ M3a.5/M3a.6（侧边栏）→ M3a.7/M3a.8（菜单重规划）`。

**M3a 验收标准**：
- 「新对局…」弹出对话框，可一次选定 模式/大小/执子/难度，局内无法再改。
- 人机对弈支持 猜先，结果明确公布。
- 摆棋模式下聊天面板可用：能答「谁领先」「我该下哪（高亮）」等。
- 侧边栏关闭后可由「视图」菜单或工具栏重新打开，且支持「+ 新对话」。
- 菜单栏不再出现 9/13/19 与独立「难度」入口。

## 4. 与设计文档的偏差记录

| 项 | 设计 | 实际 | 说明 |
|---|---|---|---|
| LLM 传输 | SSE 流式 | 非流式 | 简化，流式列入 M4.1 |
| 校验器 | 输出 vs facts 比对回退 | 模板诚实条款 | 简化，LLM 层靠提示词约束 |
| KataGo 强度 | humanSLProfile 实测标定 | 未实测 | 本机无 KataGo；参数表已预留 |
| 难度入口 | 新对局对话框 | 当前为「难度」菜单 | M3a 迁移 |
| 新对局 | 对话框 | 当前为固定菜单项 | M3a 重构 |
